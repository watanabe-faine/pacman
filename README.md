# クラフトパックマン

ダイヤ装備の勇者がエンダードラゴン風のゴーストに挑む、マインクラフト風のパックマンです。ブラウザで遊べて、HTMLファイル1つで動き、インストールは不要です。

## 遊び方

`public/index.html` をブラウザで開くだけで遊べます。Cloudflare Workers には `npx wrangler deploy` で公開できます。

| 操作 | パソコン | スマホ |
| --- | --- | --- |
| 移動 | 矢印キー / WASD | 迷路をスワイプ、または十字ボタン |
| スタート | Enter / Space | スタートボタン |
| 一時停止 | P / Esc | 一時停止ボタン |

## ルール

- 迷路の経験値オーブ（10点）をすべて集めるとステージクリア
- 金のリンゴ（50点）を食べると、しばらくドラゴンを倒せる（200 → 400 → 800 → 1600点）
- ボーナスアイテム（リンゴ・パン・ケーキ・エメラルド・ダイヤ）はステージごとに変わる
- 10,000点で勇者が1人増える

## かんたん設定

- 残機5（10,000点ごとに1人増える）
- ドラゴンは遅め、金のリンゴの効果は10秒
- ドラゴンが散らばる時間を長めにしている

## ドラゴン

| 名前 | 性格 | 動き方 |
| --- | --- | --- |
| 赤目ドラゴン | 追いかけ | 勇者を直接追う |
| 紫目ドラゴン | 待ち伏せ | 勇者の4マス先を狙う |
| 青目ドラゴン | 気まぐれ | 赤目ドラゴンと挟み撃ちを狙う |
| 橙目ドラゴン | お惚け | 近づくと離れていく |
