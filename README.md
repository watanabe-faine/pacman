# おやじパックマン

主人公がブロック風のおやじになった、ブラウザで遊べるパックマン風のアーケードゲームです。HTMLファイル1つで動き、インストールは不要です。

## 遊び方

`public/index.html` をブラウザで開くだけで遊べます。Cloudflare Workers には `npx wrangler deploy` で公開できます。

| 操作 | パソコン | スマホ |
| --- | --- | --- |
| 移動 | 矢印キー / WASD | 迷路をスワイプ、または十字ボタン |
| スタート | Enter / Space | スタートボタン |
| 一時停止 | P / Esc | 一時停止ボタン |

## ルール

- 迷路のドット（10点）をすべて食べるとステージクリア
- パワーエサ（50点）を食べると、しばらくゴーストを食べられる（200 → 400 → 800 → 1600点）
- フルーツはステージごとに種類と点数が変わる
- 10,000点でパックマンが1人増える

## かんたん設定

- 残機5（10,000点ごとに1人増える）
- ゴーストは遅め、パワーエサの効果は10秒
- ゴーストが散らばる時間を長めにしている

## ゴースト

| 名前 | 性格 | 動き方 |
| --- | --- | --- |
| アカベイ | 追いかけ | パックマンを直接追う |
| ピンキー | 待ち伏せ | パックマンの4マス先を狙う |
| アオスケ | 気まぐれ | アカベイと挟み撃ちを狙う |
| グズタ | お惚け | 近づくと離れていく |
